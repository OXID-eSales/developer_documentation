OXID Components
===============

Components are reusable libraries that provide shared functionality across multiple OXID eShop modules.
Unlike modules, components are not installed standalone but serve as dependencies for modules that need
common capabilities such as payment processing or data synchronization.

For a general introduction to the component concept in OXID eShop, see
:doc:`Components </development/modules_components_themes/component>`.
